# cisco-packet-tracer-project
# پروژه شبکه سازمانی با Cisco Packet Tracer

این پروژه شامل پیاده‌سازی یک شبکه سازمانی کوچک با استفاده از تجهیزات سیسکو در نرم‌افزار Packet Tracer است.

## مهارت‌های پیاده‌سازی شده:
- ✅ ایجاد و مدیریت VLANهای Sales و Tech
- ✅ پیکربندی Access و Trunk
- ✅ راه‌اندازی EtherChannel با LACP
- ✅ پیاده‌سازی Inter-VLAN Routing با Router-on-a-Stick
- ✅ پیکربندی DHCP
- ✅ بررسی و پیکربندی STP و Root Bridge
- ✅ تست و عیب‌یابی ارتباطات بین VLANها و کلاینت‌ها
